# 06 — COMENTAR

**Objetivo:** convidar a uma resposta relevante que possa orientar conversas futuras.

**Contexto adequado:** quando houver uma pergunta genuína e fácil de responder sobre o tema.

**Estrutura:** pergunta específica + convite opcional para comentar.

**Campos variáveis:** `[CTA]`, `[COMMENT_QUESTION]`, `[TOPIC]`.

**Exemplo genérico:** “Qual parte de `[TOPIC]` você gostaria de ver explicada em outro vídeo?”

**Restrições:** evite pedidos vagos de engajamento, comentários manipulativos ou solicitação de dados pessoais.
