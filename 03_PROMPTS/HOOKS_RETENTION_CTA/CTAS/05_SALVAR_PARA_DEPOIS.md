# 05 — SALVAR PARA DEPOIS

**Objetivo:** convidar a pessoa a guardar o conteúdo para consultar futuramente.

**Contexto adequado:** quando o vídeo traz etapas, dicas ou informação útil para referência posterior.

**Estrutura:** convite opcional para salvar + motivo específico relacionado ao conteúdo.

**Campos variáveis:** `[CTA]`, `[CONTENT_VALUE]`, `[SAVE_ACTION]`.

**Exemplo genérico:** “Se esta sequência sobre `[TOPIC]` for útil depois, salve o vídeo para consultar.”

**Restrições:** use apenas se a plataforma de publicação oferecer essa ação; não condicione acesso a informação a engajamento.
