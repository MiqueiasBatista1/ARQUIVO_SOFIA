# 05 — DESCOBERTA

**Objetivo:** apresentar uma informação ou etapa recém-introduzida no contexto do vídeo.

**Quando usar:** quando houver uma descoberta real ou uma explicação nova para o público, não uma experiência fabricada.

**Estrutura:** contexto de descoberta + o que será explicado ou demonstrado.

**Campos variáveis:** `[HOOK]`, `[DISCOVERY]`, `[TOPIC]`, `[SCRIPT]`.

**Exemplo genérico:** “Acabei de perceber um aspecto de [TOPIC] que vale explicar.”

**Restrições:** não encenar uma descoberta espontânea como experiência real se ela foi roteirizada; não insinuar novidade exclusiva sem confirmação.
