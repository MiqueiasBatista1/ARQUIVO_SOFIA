# 06 — ERRO COMUM

**Objetivo:** chamar atenção para um erro recorrente e apresentar uma explicação útil.

**Quando usar:** quando o erro estiver documentado ou for demonstrável sem depreciar o público.

**Estrutura:** nomear o erro com precisão + explicar a consequência observável ou a correção que o vídeo abordará.

**Campos variáveis:** `[HOOK]`, `[COMMON_ERROR]`, `[TOPIC]`, `[CORRECTION]`.

**Exemplo genérico:** “Um erro comum ao organizar [TOPIC] é pular esta etapa.”

**Restrições:** não chamar uma preferência de erro factual, culpabilizar o público ou inventar consequências.
