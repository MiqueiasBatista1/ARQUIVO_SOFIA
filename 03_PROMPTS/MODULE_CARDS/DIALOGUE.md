# DIALOGUE

**Use quando:** a peça incluir fala direta, narração ou texto destinado à geração de voz. O campo contém as palavras faladas, não instruções de atuação.

**Combine com:** `SCRIPT` para alinhar as falas à sequência; `MOOD` para orientar o tom e `DURATION` para ajustar o volume de texto. Se não houver voz, omita este módulo.

**Bloco reutilizável:**

```text
Fala/narração: [DIALOGUE]. Preserve o texto aprovado; não acrescente testemunhos, alegações ou detalhes não fornecidos.
```

**Exemplo preenchido:** `DIALOGUE = “Veja esta demonstração do organizador compacto e confira os detalhes do produto.”`.
