# LOCATION

**Use quando:** o contexto físico contribuir para compreender a situação ou o uso do produto. Descreva o local, sem repetir toda a ação.

`LOCATION` é o lugar físico; `SCENE` é a situação visual mais ampla e `CONTEXT` a circunstância narrativa/de uso. São campos distintos, conforme [`GLOSSARIO_CANONICO.md`](../GLOSSARIO_CANONICO.md).

**Combine com:** `ACTION` para situar o uso e `CAMERA`/`LIGHTING` para capturar o ambiente. Para sugestões por tipo de cena, consulte `IMAGE_PROMPTS/`.

**Bloco reutilizável:**

```text
Local: [LOCATION]. Inclua somente elementos ambientais coerentes com esta situação.
```

**Exemplo preenchido:** `LOCATION = mesa de trabalho em um ambiente doméstico organizado`.
