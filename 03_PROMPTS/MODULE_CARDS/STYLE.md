# STYLE

**Use quando:** selecionar a camada geral de acabamento visual da peça. Use um preset principal por peça ou plano, salvo transição intencional.

`STYLE` é acabamento visual; `MOOD` é tom emocional. São conceitos distintos, conforme [`GLOSSARIO_CANONICO.md`](../GLOSSARIO_CANONICO.md).

**Combine com:** `CAMERA` e `LIGHTING`; para estilos prontos, escolha uma opção em `STYLE_PRESETS/`. Este módulo não define identidade ou características de uma pessoa.

**Bloco reutilizável:**

```text
Estilo visual: [STYLE]. Aplique o acabamento sem alterar a identidade ou os detalhes factuais do produto.
```

**Exemplo preenchido:** `STYLE = casual`.
