# Exemplo genérico — referência hipotética

Este exemplo é inteiramente hipotético. Não descreve nem analisa um vídeo real, não usa produto comercial e não contém métricas de desempenho.

## Desmontagem resumida

1. **Contexto:** `[REFERENCE_CONTEXT]` = “clipe hipotético curto, com imagem e áudio disponíveis apenas para este exemplo”.
2. **Objetivo observado:** `[OBSERVED_OBJECTIVE]` = “o clipe mostra uma sequência de organização”; classificação: `OBSERVADO` para a ação visível, `INTERPRETADO` para o objetivo comunicativo.
3. **Hook:** `[OBSERVED_HOOK]` = “abertura hipotética apresenta uma pergunta sobre a sequência”.
4. **Retenção:** `[OBSERVED_RETENTION]` = “a resposta é adiada até a etapa final”; localização: `[EVIDENCE_LOCATOR]`.
5. **Roteiro:** `[OBSERVED_SCRIPT]` = “contexto → etapas de organização → quadro final”.
6. **Diálogo:** `[OBSERVED_DIALOGUE]` = “uma pergunta curta e uma explicação”; sem transcrição inventada.
7. **Ação:** `[OBSERVED_ACTION]` = “itens são organizados em etapas”.
8. **Demonstração:** `[OBSERVED_PRODUCT_DEMO]` = “nenhum produto é especificado; o exemplo trata somente de uma ação genérica”.
9. **Câmera:** `[OBSERVED_CAMERA]` = “não especificada além do que poderia ser diretamente percebido”.
10. **Enquadramento:** `[OBSERVED_FRAMING]` = “o espaço de trabalho permanece visível”.
11. **Movimento:** `[OBSERVED_MOVEMENT]` = “não inferir movimento de câmera sem evidência”.
12. **Iluminação:** `[OBSERVED_LIGHTING]` = “não especificada”.
13. **Ambiente:** `[OBSERVED_ENVIRONMENT]` = “superfície de trabalho genérica”.
14. **Ritmo:** `[OBSERVED_PACING]` = “uma etapa sucede a outra; duração e cadência exatas não foram medidas”.
15. **CTA:** `[OBSERVED_CTA]` = “não observado neste exemplo hipotético”.
16. **Mecanismo:** `[INTERPRETED_MECHANISM]` = “a sequência pode facilitar acompanhamento por mostrar uma etapa de cada vez”; isso é interpretação, não resultado comprovado.
17. **Padrão reutilizável:** `[REUSABLE_PATTERNS]` = “apresentar contexto antes da sequência e encerrar após a última etapa”.
18. **Não copiar:** `[NON_COPYABLE_ELEMENTS]` = “redação, identidade, composição e ativos específicos da referência original, caso existam”.
19. **Remodelagem:** `[REMODELING_OPPORTUNITIES]` = “criar nova situação, texto, enquadramento e sequência de ação para outro conceito original”.
20. **Hipótese:** `[HYPOTHESES_TO_TEST]` = “uma sequência com etapas identificadas pode ser mais fácil de acompanhar que uma sequência sem marcadores; comparar versões mantendo as outras variáveis constantes”.

## Conversão em estrutura original

```text
NOVO_CONCEITO: explicar [TOPIC] com contexto breve e etapas claramente ordenadas.
HOOK: [HOOK]
RETENTION: revelar uma etapa por vez e concluir a pergunta apresentada.
UGC_TEMPLATE: [UGC_TEMPLATE]
ACTION: [ACTION]
CTA: [CTA]
HIPOTESE: [HYPOTHESIS]
```

O exemplo ilustra a passagem de observação para padrão e hipótese. Não afirma que a estrutura aumente retenção ou desempenho.
