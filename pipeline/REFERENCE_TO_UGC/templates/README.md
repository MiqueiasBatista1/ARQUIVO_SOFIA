# Templates de remodelagem

ugc_concept.template.json é um formulário vazio para preencher com um conceito novo. Não contém produto, benefício, diálogo, aparência ou valores presumidos.

Preencha usando a saída de REFERENCE_ANALYSIS, aplique TRANSFORMATION_RULES.md e valide com schemas/ugc_output.schema.json. Campos opcionais em conteúdo são representados por null; a chave continua presente para manter o contrato estável.
